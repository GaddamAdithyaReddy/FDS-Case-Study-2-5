# Case Study: Clustering Analysis and Wine Quality Assessment

This case study covers two data analysis tasks using Python: customer segmentation through clustering and wine quality assessment using physicochemical properties.

## Part 1: Clustering Analysis

This task applies clustering techniques to customer data to identify distinct customer segments.

**Key steps:**
- Data preprocessing and feature scaling
- Exploratory data analysis and correlation analysis
- Clustering using K-Means, Hierarchical Clustering, and DBSCAN
- Cluster interpretation and visualisation using PCA
- Evaluation and comparison of clustering methods

## Part 2: Wine Quality Assessment

This task explores the relationship between physicochemical properties and wine quality and uses predictive modelling to estimate quality scores.

**Key steps:**
- Statistical analysis and exploratory data analysis
- Analysis of quality-score distributions and alcohol content
- Correlation analysis of physicochemical properties
- Predictive modelling and performance evaluation
- Discussion of practical applications and model limitations

## Tools and Technologies

- Python
- Jupyter Notebook
- pandas and NumPy
- Matplotlib and Seaborn
- scikit-learn

## Objective

The objective is to apply data science techniques to real-world datasets, interpret the results, evaluate model performance, and understand the practical applications and limitations of the methods used.
